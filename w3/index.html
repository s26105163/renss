中文程式碼解析與說明

  • FileReader 避開 CORS： 使用 JS 的 FileReader.readAsDataURL() 將本地圖片轉為 Base64 格式，避免外連圖片跨域導至無法下載的問題。
  • 文字黑邊效果： 利用 CSS 的 text-shadow 八方向陰影疊加，確保文字在任何底圖上都能清晰顯示。
  • 一鍵截圖下載： 透過 html2canvas 將 HTML #memeContainer 節點渲染為 Canvas 並輸出成 PNG 檔。

Penjelasan Singkat (Bahasa Indonesia)

  • Mencegah CORS Error: Menggunakan FileReader JS untuk membaca gambar lokal menjadi DataURL agar tidak terkena pembatasan CORS saat diunduh.
  • Teks Meme Kontras: Menggunakan text-shadow CSS untuk memberikan outline hitam tebal pada teks di atas gambar.
  • Fitur Unduh 1-Klik: Memakai library html2canvas untuk mengubah elemen preview menjadi gambar PNG (my-meme.png).
